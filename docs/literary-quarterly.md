# v2.8 · 成帙：文学季刊

## 范围与入口

`/journal` 为公开的征稿与刊期目录；`/journal/mine`、`/journal/new?issue=…` 和 `/journal/submission/[id]` 为本人投稿；`/journal/review`、`/journal/edit/[id]` 为站长编刊案头。首期不预置内容，不自动创建刊期、不代用户投稿或授权。每期最多24篇，每篇一万字；往期与编辑来稿分页。沿用原账号、邀请、libSQL和R2架构；无新的付费接口或依赖。

## 两段授权与封存

- 未勾提交的稿件为本人私存，编辑无读取入口。投稿须勾选编辑审阅授权并确认有权投稿。只存作者主动填写的文本，不查询或导入历史私信、雅集、札记或游记。
- 站长建立刊期草稿、开放征稿、选择文章/栏目/篇序，进入校样确认。编辑只能提出新的标题/正文，不可替作者确认；署名只能作者修改。
- 作者在本人页核对标题、署名、正文、栏目、篇序、刊名、刊期和刊首语，可下载本人校样PDF；明确授权此版本公开和PDF收录。本人校样不包含其他人的待刊稿。
- 内容、署名修订取消本稿确认；刊期、刊首语、选稿与编排改变提升刊期版本，使全部旧确认失效。服务器在同一写事务里验证稿件/刊期修订号、角色与当前状态，不采信客户端确认标记。
- 校样状态至少1篇且不超过24篇，全部选稿未隐藏、作者未停用，且双版本确认有效才可刊行。刊行后不允许编辑或作者悄悄改写文本/元数据；需新一期重新投稿授权。
- 作者随时可撤稿，编辑不能再阅撤稿正文，作者本人保留原文。站务隐藏/恢复留有原因与审计；恢复不越过作者撤稿或整期撤回。整期撤回不可直接重新刊行。
- 公开文章支持反馈，留当时公开版本快照；站务不追踪后来私密改写。已登录读者的双向屏蔽同样过滤在线与PDF文章。匿名已刊内容公开，屏蔽不能让已公开文字对所有人保密。

## PDF、中文字体与成本

服务器现场生成真正的 `application/pdf` 附件；公开下载与本人校样都 `private, no-store`，不存公开对象、不缓存含稿正文。下载时重新取可见文章，不含撤回、隐藏、停用作者或被屏蔽的内容；旧下载链接不会绕过权限。已下载或复制的文件不能追回，投稿、确认、刊行与阅读页均有提示。

PDF提供封面、刊首语、目录、独立起页的文章、页码；保留原稿繁简、分行和自注，自注转文末注。使用现有fonteditor-core和已安装的Noto Serif TC/SC字体，从WOFF抽取实际字符，嵌入TrueType子集与ToUnicode文本映射。可离线阅读与复制文本，不依赖阅读者安装中文字体、不调用浏览器或付费PDF服务。字库覆盖16,136个字符，未覆盖少见字显示缺字框，同时在PDF末页列出Unicode字码供在线原文核对；校样确认页明确提醒。字体许可位于 `/fonts/journal/OFL.txt`，重建索引命令 `node tools/prepare-journal-fonts.cjs`，无需联网。

每期最多500页，PDF下载有频率限制以控制CPU；使用现有Vercel函数、数据库及传输额度，不能承诺无限流量免费。失败时可使用在线版浏览器打印另存PDF。此PDF未宣称PDF/UA完整无障碍标记，网页保留普通标题/目录/正文结构。

## 发布与回退

schema 8仅新增journal_issues、journal_submissions、journal_reports及索引；不回填、删除或变更旧信、邀请、附件。生产先运行现有backup workflow的migrate操作：一致性导出、附件导出、隔离恢复、加密上传成功后升级，再合并和部署。回退应用时保留这些新增表和稿件；不可删除季刊数据或把曾撤回文章重新公开。备份私钥不进入仓库。

验证重点为双段授权、私存与编辑权限、版本变化取消确认、发布原子校验、撤稿及隐藏过滤、真实表单/HTML/RSC权限边界，以及中文PDF字体嵌入、文本抽取和长文分页。匿名测试数据不写生产。
