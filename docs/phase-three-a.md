# 第三阶段首批：和鸣

本轮交付唱和、自注和题跋；下一批再做有起止时间和集序归档的雅集。沿用 Next.js、libSQL、原账号/雅号、邀请、私信及屏蔽机制，未重写现有寄信系统。

## 功能及边界

- `/literature` 展示公开卷、自己的私卷及收到的卷邀，按时间分页，无热度、排名或公开计数。`/literature/new` 以一首诗或自由创作起卷，支持卷名、小序、可选韵脚及二至二十四人的上限（默认十二，含起首者）。韵脚不作格律检查。
- 起卷默认私密，名单在起卷时题定。受邀者应邀后可看全卷，未应邀只见卷邀资料。私卷不自动扩大范围、不提供无授权的转公开操作。公开卷须显式选择并确认范围；后续加入者也需确认雅号随卷展示。
- 邀请私卷复用既有可通信关系中的笔友/已来信者；起首者可撤回入卷权限，各人可离卷。离卷后，作品作者仍可通过“我的篇章”读取、收回自己的原文，不能借此读取其他篇章。
- `/literature/[id]` 横向展卷并提供逐篇阅读切换；每人同卷一篇，序号通过写事务分配，成员/受邀席位均计入内部容量。起首者可封卷，停止加入与接续。首版作品定稿后可收回展示，暂不改写已入卷原作。
- `/works/[id]` 独立阅读自己的或有权访问的作品，直排可选。自注语法为 `[[词语|解释或出处]]`；原文完整保存，错误语法原样显示。自注按钮支持键盘聚焦、点击与 Escape，浮层兼容手机和直排，React转义文本而不解释HTML。
- 写作文字在当前标签页 sessionStorage 内暂存，以账号及目标分键；不会暂存或恢复公开/授权勾选。关闭标签页可能清除，成功提交后清除。此功能不冒充服务端草稿。
- 百字题跋先仅题跋者/作品作者可见，作品作者收录后按原作品范围展示；题跋者可随时收回（作品作者也不再读到撤回文本）。无累计数量或排名；未授予别处书斋陈列、转载及出版权限。题跋列表分页。
- 既有已送达公开尺牍可用题跋；私人信、未来信、阅后即焚不接入。新公开批注走作者收录的题跋流程，旧制历史批注保留，不自动转为已授权题跋；私人信的原批注继续使用。
- 起卷每天三次、和作五次、题跋十次、反馈十次，操作入口每分钟六十次。限流只作后台防骚扰，不变成公开指标。起卷与接续均有幂等键，屏蔽关系在事务内重查，不容借同卷接续或题跋绕过。
- 作品/卷可反馈给站长；`/literature/review` 只有站长可阅反馈及对应的被反馈内容，不能据此遍历其他私卷。可隐藏/恢复，写入原有 admin_audit，不改写正文。

## 增量数据库

schema版本4新增 literary_spaces、literary_members、literary_entries、literary_colophons、literary_reports。唯一索引保护起卷/入卷/作品顺序/每人同卷一篇与题跋归属。不删除或改写历史账号、邀请、信件与草稿，无默认公开回填。时间以UTC毫秒存储，后台每日限流按既有公共时区分日。

发布前采用既有 backup 工作流：生产一致快照与附件备份、隔离恢复、加密上传成功后，再运行 upgrade-schema.cjs；无需重跑图片迁移或删除。增量DDL短暂串行写入，无计划停机。

回退保留新结构，不删新作品；可关闭新入口并前向修复授权。已有私卷不得通过回退被自动公开。每日备份自动覆盖新增表，沿用原有加密与保留策略。

## 成本和验收

只有文本及自注，没有新附件、收费依赖或外部通知渠道。主要改动为 literary-policy/service/actions、LiteraryForm、AnnotatedText、ColophonSection，新增唱和及作品页面，扩展公开信阅读/批注入口、导航、迁移、简繁字典与更新日志。

必要检查：真实隔离库内的私卷可见范围、容量并发、顺序、幂等、屏蔽、离卷/收回、题跋收录/撤回、治理权限；实际HTTP响应与表单提交不泄露私卷/待收录题跋；类型检查和生产构建。只做与改动相称的一轮检查，失败或新改动才扩展。

人工体验：起私卷并邀笔友；应邀前看不到正文，应邀后接续和作；横向与逐篇、直排切换，点击/键盘读注；另一书友题跋，作者收录，再收回；撤回成员权限、封卷、从“我的篇章”找回自己的原文。登录全流程及手机视觉若未实际人工操作，不声称已验收。
