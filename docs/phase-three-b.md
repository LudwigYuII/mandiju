本轮完成雅集与集序，保留 Next.js 15 / React 19 / libSQL / R2、旧账号、邀请、尺牍和唱和。没有进入第四阶段。

## 行为与边界

- `/gatherings` 分页列出公开席、自己的雅集与收到的私席邀请；`/gatherings/new` 题定主题、小序、开始/结束时间与席位上限。默认私席、十二人，允许二至二十四人（包括主人与预留邀请）。未来一年内开始、最长七日，后台每日创建三场、留文二十篇。
- 时间表单明确标注公共活动时区，服务端解析为 UTC 毫秒；遇夏令时缺失或重复分钟拒绝模糊时间。每场记录创建时的时区，不因未来站点时区更改而改变既定时间和显示。
- 私席邀请沿用笔友/已收来信关系。受邀者只见邀约题头，主动入席后才能读正文。名单与范围创建后不扩张；公开席访客可读，登录后入席。婉谢、离席、撤权后不能重新入席；往来屏蔽阻止新的入席和留文，主人屏蔽时暂停私席访问。
- 留文仅在开始时刻（含）至结束时刻（不含）接受，按服务器时间、ID稳定分页排序。不轮询、不实时聊天，无在线/已读/输入状态与公开互动计数。原文与自注保留；定稿不可编辑，作者可以收回。
- 雅集到期后直接由同一条规范记录呈现只读集序，不另复制正文，也不依赖定时任务触发才能关席。每次服务端读取按截止时间过滤：只返回单篇明确同意归档的原文与署名，名录仅列单独授权留名的已入席者。题头（主题、简介、时间、主人雅号）经创建时明确同意保留。私席集序继续限主人和获准成员，未应邀者仅见原邀约题头。
- 每篇文字的展示确认与归档授权独立，归档默认未勾选；同意归档即包含该篇署名。名录授权也独立、默认未勾选。结束后不能追加文字、扩大归档授权、加入成员或改变范围。撤回归档/展示和站长治理仍允许；不承诺不可撤回的永久出版。
- 离席或主人撤回席位，会同时收回该人在此席的文字展示与名录授权；原文仍在 `/gatherings` 的本人记录中可查。未授权归档的文字结束后也仅本人记录可读，不向主人保留额外读取后门。主人可提前散席，不可续开。
- 内容反馈与站长隐藏/恢复有审计，结束后仍可治理。页面文本沿用简繁显示机制，作者原文不转换；写作沿用标签页草稿。没有附件上传与新增收费服务。

## 已知限制

活动名录是用户主动入席并同意留名的名单，不记录在线时长或实时出席。未获准归档的正文保留给作者自行找回，不是到期自动物理删除。集序没有额外导出、出版、推送提醒和编辑排版；后续季刊/出版需另行授权。归档展示为到期后的服务端即时投影，用户访问页面即可看到；无需并未新增后台归档作业。此前未确认的旧 CDN 缓存清理、高频投递调度不在本轮完成声明内。
