# 第四阶段首批：v2.6 · 岁读

本轮完成节气与岁时、应节雅集、共读抄书；云游地图与季刊留待本阶段下一批，不进入第五阶段。保留原Next.js 15 / React 19 / libSQL / R2、账号、邀请、寄信、书斋和雅集架构。

## 功能与默认范围

- 首页保留书案结构，新增小幅四时题字、原创枝叶线图与辅助色；正文仍用原纸墨色，不增加动画、第三方图片或定位。按最近节气选择四时，不把站点岁时当成全球用户当地天气。
- `/seasons` 区分二十四节气、农历节日和其他公历节日，展示近期节令及应节雅集。`data/seasons.json` 集中维护节日规则、开席节令、四时辅助色和题字；农历日期沿用 lunar-typescript，闰月不重复普通农历节日，不写死年份日期。
- 首批在立春、清明、立夏、夏至、立秋、冬至、小雪、元宵、中秋、重阳开设站务公开雅集，默认十二席（含站务主人）。只创建预设主题和说明，不引用私人作品；需已有未停用且题过雅号的站长，没有合适主人时不造账号、不强行开席。
- 应节雅集按当天公共时区起讫，复用原有入席、席位、屏蔽、留文与集序授权。当天事件有唯一记录；隐藏、封席或重复执行不会再造一席。通过原 `/api/cron` 及雅集/岁时页面访问补足创建，原定时配置不改，不宣称此前未配置的高频投递已启用。任务延迟或无人访问不会丢失用户文字；本轮不补建错过的历史活动。
- `/reading` 每日一段古文，所有人可读原作及来源；抄写和札记需登录且有雅号。今日可自愿参与，不要求抄满、不检验相似度、不记录连续天数，也不公布参与人数。
- 抄写仅本人可见。札记默认私密，作者主动勾选后才与雅号分享给同一日的参与者（包括当天后来参与者）；不会自动公开到书斋、搜索、季刊或其他日期。只在用户明确确认参与后建立资格，公共原文页面和响应不携带其他人的私人抄写。
- 收卷后不再接纳新参与，也不能改写抄写/札记或扩大分享；原参与者可回看该日已经授权的札记。随时可撤回分享或退出此日；退出后自己也失去同日他人札记访问，不重新入席，自己的原文在 `/reading/mine` 保留。
- 双向屏蔽即时过滤双方札记；写操作有既有账号检查和后台限流。资料修订号防止旧标签页覆盖，当前标签页文字暂存复用原流程，不保存/恢复授权勾选。札记每页20篇，不轮询、不催答、不做热度排序。
- 札记可以反馈；`/reading/review` 只供站长阅读已反馈那次文字快照，不读取私人抄写，也不跟随作者后来改写的新私人札记。提交时明确告知有限反馈证据；隐藏/恢复留审计，恢复不会越过作者撤回或退出状态。

首批四篇、八段节选轮读：苏轼《记承天寺夜游》、刘禹锡《陋室铭》、周敦颐《爱莲说》、张岱《湖心亭看雪》。古文原作是公版；数字化文本参考维基文库固定版本及贡献者，文本数据依CC BY-SA 4.0保留署名和相同方式共享说明，链接许可页，不收入现代译文、现代注释、书影或第三方版式。

`data/reading-catalog.json` 保留稳定版本ID、书名、作者、固定来源、许可、许可地址、权利说明和2026年11月17日核对日期；节选分段由本站编排。首次当日阅读将对应版本钉定，后续目录新增不会改写旧日期。变更正文或版本须用新ID，不覆盖已存在的文本版本。首批八段按日期循环；不是无限书库或每日新增原创文章。

## 增量结构、兼容和成本

schema 6新增 library_books、library_passages、reading_days、reading_entries、reading_reports、seasonal_gatherings 六张表及索引，均在原增量写事务内执行。不回填/公开旧信、不删除账号和作品、不重跑附件迁移，无计划停机。

每日共读以 UTC 毫秒记录起讫并钉定公共时区，读写不依赖服务器本地时区；初始Asia/Shanghai。遇不明确的午夜时区边界不擅自猜测，报错并保留已有数据。应节雅集记录自身时区，之后站点配置变更不改写旧活动。

幂等创建采用事务、唯一索引，短暂写锁争用只对日历供给作有限重试；用户写入不盲目重放。定时任务依然校验CRON_SECRET，不新增密钥、收费服务、地理位置、图片上传、邮件或外部运行时API。新增成本为少量文本和数据库读写，列表分页。

回退可移除新入口、回退应用提交，保留schema 6和原文；不要删表回滚。已经产生的应节雅集仍可由v2.5展读，其集序授权沿用原规则。文本数据已经钉定，不能通过回退把私人抄写公开。
