# v2.7 · 云踪：全球云游地图

第四阶段第二批，按用户明确选择直接面向全球，不再限试点区域。沿用Next.js 15 / React 19 / libSQL / R2与原账号、邀请、寄信、书斋、雅集架构。本轮只开发云游地图，季刊另批，不进入第五阶段。

## 已实现及入口

- `/travel` 全球陆地轮廓图，公开游记以同样大小的墨点呈现；按地区或篇名/地名检索。列表按创建时间分页，每页20篇；地图最多展示当前筛选最近300篇，不用于排名/热度，更多内容可翻页。无打卡总数、粉丝、排行榜或路线追踪。
- 图面支持按钮缩放/平移、鼠标与触控拖动、方向键及加减键，限制为适合概览的缩放级别；同时提供文字列表，地图或JS未加载不阻断文字阅读。首版不是街道导航。
- `/travel/new` 写游记，`/travel/[id]` 展读并支持既有自注；`/travel/[id]/edit` 修订；`/travel/mine` 私人管理；`/travel/review` 站长治理。
- 全文仅文字，最多一万字；可写回忆或历史地名，不要求提供到访证明，不收集到访时间、住址、实时位置或定位权限，不上传照片。原有 `/map` 私人往来地名保留，不把旧信地名迁移到公共地图。
- 资料库支持全球7,342个城市/地点，以中文、繁体中文、外文及原有别名检索，返回最多20项。没有覆盖所有街道和小聚落；没有的地点可以地图手动选点或键入经纬度，并自题地名。历史地名与现代参考地名分开保存，不冒充经过考证的历史坐标。
- 资料库地点通过稳定Natural Earth ID在服务端重查，客户端伪造名称/坐标不替换规范数据；手动选点校验经度[-180,180]、纬度[-90,90]及有限数字，并粗略推断地区。手动地名明确标注未经资料库核对，不能仅凭经纬度证明某个地名真实。坐标统一只保留两位小数（约公里级，随纬度变化），不宣称高精度。

## 免费方案及来源

采用Natural Earth公有领域数据，官方许可：https://www.naturalearthdata.com/about/terms-of-use/ 。底图只画简化陆地轮廓，不画国家边界。原始地名/地区标签保留资料来源，不根据文字体系推断用户身份。

所用源文件来自 https://github.com/nvkelso/natural-earth-vector ，下载时上游HEAD为ca96624a56bd078437bca8184e78163e5039ad19，获取日期2026年11月17日：
- geojson/ne_110m_land.geojson：生成静态陆地路径。
- geojson/ne_10m_populated_places.geojson：选取名称、别名、稳定ID及坐标。
- geojson/ne_10m_admin_0_countries.geojson：补充城市的地区标签。
- geojson/ne_110m_admin_0_countries.geojson：仅服务端粗略判定手动点所属大区，不绘制政治边界。

衍生素材：`public/geography/world-land.json`约70.8KB；`data/geography/places.json`约776.6KB；`data/geography/regions.json`约246KB。后两项只在服务端使用，不整包送到浏览器。`data/geography/sources.json`记录源版本、许可和SHA-256；`tools/prepare-geography.py`从已下载的上述原文件重建素材，不读取用户内容。

页面保留Natural Earth来源与许可链接。运行时底图从本站加载，地点搜索通过本站`/api/travel/places`，不调用第三方地图瓦片、地理编码或定位接口，无API密钥、计次付费、外部地图配额或新的收费服务。原网站托管、带宽和数据库仍按既有资源消耗；不能把不新增地图服务费说成服务器资源永远无限免费。

## 私密、公开、修订及治理

游记默认仅本人可见；公开须独立确认正文、雅号、地名与地图坐标会展示。文字暂存沿用当前标签页机制，不保存公开/授权勾选。公开后没有季刊、转载或商业许可。

私人游记不进入任何公共墨点/列表，包括作者自己浏览公共地图时也不混入。所有阅读/修订在服务端校验；猜中资源ID仍不可读私人正文/地点。收回公开后旧阅读链接不再向他人提供文章，公共墨点与列表同步过滤；本人仍可回看和修订。公开文字可能已被他人复制，界面明确站内撤回无法收回第三方副本。

修订号防止旧标签页覆盖；首次提交使用稳定键实现幂等，保留原文空白与自注。默认每日最多20次保存、每分钟60次请求，仅后台防滥用，不形成社交指标。双向屏蔽过滤双方已登录阅读/列表，并阻止对方反馈；公开内容对匿名访客仍属公开，不承诺屏蔽能够删除他人离线副本。

公开游记可反馈。站长只通过已反馈目标的当次标题/正文快照处理，不读取后来改成私密的新版本；告知有限反馈证据保留。隐藏/恢复记入admin_audit，恢复不改变作者可见范围；被隐藏的文章仅作者可读。

动态页不缓存私人内容，原Service Worker继续不缓存页面。公开底图、静态地点资料的缓存不包含用户游记。

## 数据库、兼容、回退与成本

schema 7增量新增travel_entries、travel_reports两张表和公共筛选/作者索引。地点资料随代码提供，不额外灌入几千行生产库。没有旧信或私人作品回填，没有删除/更换账号、附件和原地图，不重写现有架构，无计划停机。

回退应用入口可保留schema 7及游记原文；不删表、不过度回滚用户新内容。原版本只忽略新表，不会把私人游记转为公开。存储主要为用户文字与少量地点字段；无照片对象存储、运行时收费接口或地图密钥。

上线沿用：精确提交CI/预览成功 → 同分支backup操作migrate：生产库/附件导出、隔离恢复、加密上传同仓库Actions备份 → 增量schema 7 → 合并PR → Vercel正式部署 → 正式域名必要检查。不读取/上传用户备份私钥。
