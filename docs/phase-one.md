# 第一阶段交付与兼容说明

沿用 Next.js、libSQL、账号、邀请、寄信及私有附件，不重写系统。

## 身份与印章

新增 literary_name、literary_key、seal_style。雅号二至四汉字，NFKC 归一后以 OpenCC 的繁转简结果作为唯一键；保留站方名称，数据库唯一索引处理并发冲突。用户可自由选用简繁原文，界面切换不转换雅号。首次题定后暂不开放改名，未来修改频率及审核规则需另行确认。

旧 pen_name、密码哈希、邮箱、用户 ID、原 seal_text 保留。公开展示从 public_users 视图读取雅号；未题号者显示带匿名编号的“未题书友”，不回退原账号姓名。旧姓名书斋链接不继续公开解析。原账号邮箱登录方式不变，首页、写信、信匣等入口引导老用户题号。新用户注册时直接题号。

印章采用转义安全的 SVG 文本，支持二至四字的右起排列及阴阳刻，免收费生成服务。历史火漆字段和收藏仍保留。

草稿增加 recipient_id，并从旧笔名回填稳定用户 ID。读取草稿时显示收件人的当前雅号，原稿正文与收件人文本保留。

## 闭关与寄信

新增 retreat_until；时间按网站公共时区所选日期零时转换为 UTC。可提前出关或延长，最长一年。出关日期公开可见，不显示在线、阅读或其他活动状态。

新信 original_deliver_at 保存原定时间。发信事务内读取收件人的闭关时间，将实际开放时间设为二者较晚值。变更闭关设置与未到达新信时间的更新同处写事务；提前出关保留原定时间下限。已送达信件、上线前旧信与胶囊不回算、不延迟。任务仍由既有持久通知任务处理，重复请求仍使用同一幂等键。

既有驿马默认一至二十四小时及环境可配置范围继续复用。来信送达前无正文、无已读回执。

## 荐帖与视觉

复用 invites，无第二套邀请系统。引荐关系默认隐藏，由被引荐人勾选后，仅显示有效且已题号、未被暂停账号的引荐人雅号。没有可用引荐人时不展示旧账号姓名。

首页、写信、信匣、阅读页采用纸墨色、克制细线、阅读宽度和移动端间距；淡化旧红色内测横幅，移除入站指引中过时的邮资积分文案。

## 迁移与回退

schema_migrations 版本 2 在写事务中增量补列和唯一索引，不删除原表与历史数据。public_users 视图可在隔离恢复后重建。数据量较小时无需专门停机，SQLite 写事务会短暂序列化。发布前先执行加密备份与隔离恢复，再运行 upgrade-schema.cjs。应用回退时保留新增结构；不得公开回退到使用旧真实姓名或旧私信访问漏洞的版本。闭关期间回退尤其需要保留新的服务端送达限制。

## 验收与成本

完成类型检查、生产构建、既有回归检查及新增雅号规范化/旧身份保护检查。验证仅针对实际改动。人工验收：旧账户邮箱登录后题号；简繁同名冲突；设置阴阳印；设置闭关后寄信，提前出关/延长；勾选及隐藏引荐人；手机写信与阅读。

仅新增少量数据库字段、索引及 SVG，无新付费服务。依旧使用原 R2 存储和通知渠道。

上线收尾：定时加密备份使用已合并的新版工作流；旧公开图片的源对象与缓存撤除需独立执行，不得把新私有副本建立成功当成旧 URL 已失效。
