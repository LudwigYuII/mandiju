# 慢递局

面向中文使用者的邀请制书信网站，逐步升级为「现代文人雅集」。以被回信取代被看见，以真正的往来取代持续的曝光。

现有账号、邀请关系、历史信件、公开作品与邮票收藏继续使用。私人信件送达前不向收件人提供内容或存在记录；不展示对方阅读状态，不设积分、数量成就或刷信奖励。公开作品须主动选择。

## 技术与运行

Next.js 15 App Router、React、TypeScript、Tailwind CSS、libSQL/SQLite。保持原有架构，使用增量迁移。

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm typecheck
pnpm test
pnpm build
node tools/verify-local.cjs
```

本地初始化至少设置 `MDJ_ADMIN_PASS`；生产需要至少32字符的 `MDJ_SECRET`、真实数据库及持久的私有附件存储。不要在缺少配置时直接将整改分支覆盖生产部署。

## 上线与恢复

[四批整改、兼容性、配置、历史附件迁移及恢复说明](docs/existing-site-remediation.md)

新代码提供受权限保护的附件接口；旧公开图片地址需要迁移并撤销源站/CDN副本才能失效。备份必须在数据库与附件完整导出后加密上传。账号、邀请、历史信件和收藏不会因停用积分而删除。

## 产品原则

慢节奏、小规模、不量化；现代中文与古典表达都可自然存在。界面简繁独立于作者原文，公共时间明确，重视键盘、阅读和低负担。

有古意，而不作古；有人情，而不喧哗。
